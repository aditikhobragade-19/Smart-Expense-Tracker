Smart Expense Tracker

A Python-Based Personal Finance Management Application

Smart Expense Tracker is a desktop application developed to simplify personal financial management. It enables users to record income and expenses, manage monthly budgets, monitor spending patterns, and generate financial reports through an interactive graphical interface.

Project Overview

The application provides an organized approach to tracking daily financial activities. It combines transaction management, budget monitoring, data visualization, and report generation in one desktop solution.

Key Features

- Interactive Dashboard: Displays total income, expenses, and available balance.
- Transaction Management: Add, edit, and delete financial transactions.
- Budget Management: Set monthly spending limits and monitor budget utilization.
- Budget Alerts: Receive warnings when spending approaches or exceeds the defined budget.
- Financial Tracking: View daily and monthly income and expense summaries.
- Search & Filtering: Find transactions using titles, categories, and transaction types.
- Data Visualization: Analyze financial activities through interactive charts.
- Category-wise Analysis: Understand expense distribution across categories.
- Monthly Expense Trends: Monitor spending patterns over time.
- CSV Report Export: Export transaction records for external analysis.
- Database Integration: Store transaction records using SQLite.
- User Interface: Desktop interface with light and dark appearance modes.

Installation & Execution

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory

cd Smart-Expense-Tracker

3. Install dependencies

pip install customtkinter matplotlib

4. Launch the application

python main.py
